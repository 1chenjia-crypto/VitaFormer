Settings

Large single spheroids may fail at native resolution. Choose the size by checking masks on a few images - never by looking at the functional result you want to study. No automatic size selection is offered.

Images are processed on this computer only. Each run is saved in a new folder; nothing is overwritten and your original files are not changed.

    How to read the outputs

    • Image measurements (areas, region count, shape) come from the mask alone. "Region count" counts connected regions; touching organoids merge, so it is not an organoid count.
    • Relative to controls compares images within a group. It is not a viability percentage.
    • Calibrated predictions (for example of CellTiter-Glo) need your own assay data for fitting; this tool does not produce them.
    • Alive and Dead are model classes. Dead predictions have not been externally validated and must not be reported as cell death.
