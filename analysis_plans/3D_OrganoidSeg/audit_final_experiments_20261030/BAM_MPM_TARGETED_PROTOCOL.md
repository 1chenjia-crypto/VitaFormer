# BAM_MPM_TARGETED_PROTOCOL — BAM 与 MPM 的专项验证协议(2026-10-30 定稿,尚未执行)

原则:不预设模块有效。所有终点、分层规则、容差和统计方法在运行前冻结;阳性和阴性结果都完整报告。

## 0. 归因能力
| 对照 | 是否可单独归因 | 种子 |
|---|---|---|
| Full vs No BAM | ✅ BAM(唯一差异) | 3 |
| Full vs No MPM | ✅ MPM(唯一差异) | 3 |
| Full vs Simplified | ❌ 两个模块同时去掉,只能作为组合差异 | 3 |
| No MPM vs Simplified | ✅ 在已去掉 MPM 的条件下的 BAM 效应(交互检查) | 3 |
| No BAM vs Simplified | ✅ 在已去掉 BAM 的条件下的 MPM 效应 | 3 |

已有对照足以单独归因两个模块,**不需要新训练**。缺的是种子 3407/2026 的预测 mask(需要推理,即 Gap Audit 中的 B1)。

## 1. 数据与统计
- 数据:CRC test_cond,167 张图,154 个物理孔;其中 24 张含 Dead,22 张含 Bubble。
- 预测:每个 run 的 `best_miou.pth`,冻结推理协议(224/112,ImageNet 归一化),保存 4 类概率(uint8)和硬 mask。
  - 新输出目录:`vco/runs/module_endpoints_multiseed_<date>/`。
  - 不覆盖 Stage 30。
- 一致性检查:seed 42 的新 mask 与 Stage 30 缓存逐像素比对。预期因 fp16 只有微小差异,报告差异比例,不要求完全相同。
- 统计:对 comparator − Full 做配对层级 bootstrap,在种子和物理孔两层重抽样,10,000 次,seed 20261031,与 statistical_analysis_20261026 相同。
  - 同时报告逐种子效应及其方向一致性(n/3)。
  - Dead 和 Bubble 分析分别注明有效图像数(24 和 22)。
- 判定:效应 CI 排除 0、3/3 种子方向一致、且达到实际意义阈值,三者同时满足才称"稳定改善"。只满足部分条件写"趋势"。CI 跨 0 写"无证据"。

## 2. BAM:边界专项

### 2.1 指标(全部冻结)
- Boundary F1:主容差 2 px,敏感性 1/4/8 px,与 Stage 30 相同。
- ASSD 和 HD95(像素):只在 GT 与预测边界都非空的图上计算;空的情况单独计数。
- Boundary IoU(Cheng et al. 2021):d = 图像对角线的 0.5%,在 2048 px 图上约 14 px。
- Alive 和 Dead 的逐图相对面积误差(沿用 10-30 定义)。
- Dead 的 Precision、Recall、IoU(像素合并,沿用 10-30 定义)。
- 类别:前景(alive ∪ dead)、alive、dead、bubble。

### 2.2 分层(只用 GT 和输入图像定义,运行前冻结)
| 层 | 规则 |
|---|---|
| Dead–Alive 接触带 | GT alive 与 GT dead 边界相距 ≤ 3 px 的像素,膨胀 5 px;只在 24 张 Dead 图上计算带内边界 F1 和带内像素准确率 |
| 边界模糊 | 沿 GT 前景边界,在 5 px 带内取输入灰度的平均梯度幅值;按全测试集该值的三分位分组(低梯度 = 模糊) |
| 小面积类器官 | 每张图 GT 前景连通域面积中位数的三分位(沿用 10-30 的 size tertile) |
| 不规则类器官 | GT 连通域 solidity(面积 ÷ 凸包面积)的逐图面积加权均值,按三分位分组;最低组 = 不规则 |
| 气泡–类器官接触 | GT bubble 与 GT 前景距离 ≤ 5 px 的图(预计很少,样本数照实报告);接触带内的边界 F1 |

每层报告 n 图和 n 孔。少于 10 张图的层只做描述,不做推断。

### 2.3 实际意义阈值(预先设定)
- 边界 F1 绝对改善 ≥ 0.01(约 1 个百分点);
- ASSD 改善 ≥ 1 px(约 1–2 µm 量级,取决于像素尺寸,待确认);
- 面积误差改善 ≥ 1 pp。

### 2.4 代价检查
若 BAM 在某个终点改善,同时报告:
- 同一 run 的 mIoU 和各类 IoU 变化;
- 其他类别的边界指标变化。

### 2.5 已知前置结果(seed 42,Stage 30)
- 前景 BF1:去掉 BAM **+0.0036 [0.0005, 0.0070]**,即去掉 BAM 更好,但远小于 0.01 的实际意义阈值。
- 其余指标 CI 跨 0。
- 多种子分析只用来检验这一点是否稳定,不会因结果为阴性而改变口径。

## 3. MPM:形态先验专项

### 3.1 实现核实(已完成)
- 3 张手工图(pellucidity、对数局部方差、Sobel 梯度),逐图 min-max 归一化,在 56→112 解码阶段以 16 通道 skip 注入。
- 不可学习,无监督。
- `morph_head` 从未训练。**不做任何"形态重建"分析。**

### 3.2 实验 A:形态测量准确性(CRC GT)
- 特征(语义 mask 层面,与 Stage 30 公式相同):
  - 总面积;
  - 周长(边界像素数);
  - 圆度 4πA/P²(面积加权均值,只计 ≥ 100 px 的连通域);
  - solidity(紧致度);
  - 连通域面积分布:中位数、IQR、小于 p25 的比例;
  - Alive 面积占类器官面积比例;
  - Dead 面积比例。
- **实例限制:** 连通域不等于真实实例,接触或重叠的类器官会被合并。所有连通域级特征都标注为 "component-level";不报告实例计数准确率。
- 终点:每个特征的 |pred − GT| 除以 GT 尺度(IQR,IQR 为 0 时用 SD,沿用勘误规则)。
  - 主终点:逐图综合误差(各特征的均值)。
  - 次终点:各特征误差,附 Holm 校正。
- 比较:Full vs No MPM(主);No BAM vs Simplified(交互);Full vs Simplified(组合)。3 种子。

### 3.3 实验 B:复杂条件下的稳健性
优先使用客观分层,数据来自 B1 推理的 mask:
| 条件 | 分层规则(只用输入图和 GT) |
|---|---|
| 亮度和对比度 | 输入灰度的全图中位数,以及 p99−p1 对比度,各取三分位 |
| 高纹理复杂度 | 输入灰度的局部标准差(σ=5)全图中位数,三分位 |
| 小面积目标 | 同 BAM 小面积层 |
| 高气泡干扰 | GT bubble 面积占比 > 0 且位于上半(否则无气泡) |
| 不规则边界 | 同 BAM 不规则层 |
| 高 Dead 占比 | GT dead / (alive+dead) 在 24 张 Dead 图中位于上半 |

模拟扰动(可选,P2,需要额外推理):
- 只做 2 种冻结强度:亮度 ×0.7 / ×1.3,对比度 ×0.7 / ×1.3;
- 只在测试图上推理,Full 与 No MPM 同等对待;
- 终点为 mIoU 下降量的差异;
- 只有分层结果提示 MPM 有收益时才执行。

### 3.4 实验 C:解释忠实度(MPM 是否真的影响预测)
主检验为输入通道依赖性,推理时干预,不需要训练:
1. **MPM 置常数**:3 张先验图替换为该图自身的均值(去掉空间信息,保留量级)。
2. **MPM 跨图交换**:替换为另一张随机测试图的先验图(保留真实分布,破坏对应关系;固定配对,seed 20261031)。
3. **BAM 同理**:Sobel 通道置常数,以及跨图交换。
- 终点:
  - 与原预测相比的像素翻转率;
  - mIoU、Dead IoU 和形态综合误差的变化(相对 GT)。
- 解读:
  - 若置常数或交换几乎不改变输出(像素翻转 < 0.5%,mIoU 变化 < 0.2 pp),说明该模块的信息基本未被使用,与"可去掉不损失"的消融结果一致。
  - 若输出明显改变,但 No MPM 模型同样好,说明 Full 依赖了 MPM,但这一信息可以被替代(冗余,而不是无用)。
- 遮挡分析:对输入做 32×32 块遮挡,测 Dead 概率的下降,与 GT Dead 区域重合度用 pointing game 衡量。只在 24 张 Dead 图上做,Full vs Simplified。属可选(P2),因为它检验的是整个网络而不是 MPM。
- 参数随机化 sanity check:只有在产生显著性图时才需要;主检验不用显著性图,因此不做。
- 禁止:
  - 把 MPM 特征图或注意力图"看起来合理"当证据;
  - 把 pellucidity、entropy、gradient 与药物机制关联。

### 3.5 实验 D:下游价值(DeepOrganoid)
- 现状:只有 Full 和 Simplified 的输出,两者差异是组合差异。已知:
  - 患者系排序 Simplified − Full +0.045 [0.005, 0.103](只作描述);
  - CTG 对齐 0.779 vs 0.752。
- 可直接报告:Full vs Simplified 的组合差异,沿用 Stage 31–34 的协议,不改口径。
- 单独隔离 MPM:需要 No MPM 在 3,456 张图上推理(Gap Audit 中的 B4)。
  - **触发条件:** 只有当实验 A、B 或 C 显示 MPM 有稳定的专属收益时才做。否则不做,论文中不声称 MPM 改善药筛。
- 提醒:Stage 34 的"大小分布在条件 + 面积之上有小幅增益"(回归任务)与"最佳患者系排序来自 NEG 归一化面积"(排序任务)是不同任务的不同结论,不混写。

## 4. 停止标准
- B1 推理完成后一次性计算第 2 节和第 3 节全部终点。不追加新的指标或分层。
- 若 BAM 与 MPM 在主终点上都无稳定优势:
  - 维持冻结架构(Simplified);
  - 论文报告"为边界和形态而设计的模块在其目标终点上未显示稳定收益";
  - 不做 B4,不做模拟扰动或遮挡,专项验证结束。
- 若某个模块在某个主终点上达到"稳定改善":
  - 只在该终点上执行相应的可选实验(扰动或 B4);
  - **不回头改变冻结的主模型**。主模型由 overall 指标、稳定性和简洁性共同决定,模块的专属收益作为讨论或补充结论报告。
