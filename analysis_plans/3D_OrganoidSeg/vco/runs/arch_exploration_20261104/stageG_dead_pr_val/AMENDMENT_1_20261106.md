## 1. Decision rule (replaces D(t))
Score s = log p_dead − log max_{c ∈ {bg, alive, bubble}} p_c, from the probabilities the model's own inference produces
(VF: window-averaged softmax of infer_hard; nnU-Net: its exported softmax). Pixel = Dead iff s > δ, else argmax over the
other three. δ = 0 reproduces plain argmax (verified, see §4). Main grid δ ∈ [−4, 4] step 0.1; fine grid step 0.01 on
[−20, 20] for curves. **Plain argmax (δ = 0) remains the formal primary result.** Binary p_dead AUPRC also reported.
Stored per image: fine s-histograms by (GT class × other-argmax class), far-background histogram, p_dead histogram, a uint8
δ-level map (number of main-grid δ below s) and the other-argmax map. Raw probability tensors are not kept.

## 2. Statistical reading (replaces "CI includes 0 → equivalent")
Hierarchical paired bootstrap (3 seed positions + physical val wells, 10,000, RNG 20261107). For each contrast:
- **Difference supported:** 95% CI excludes 0.
- **Equivalence within margin supported:** 90% CI entirely inside ±margin (TOST-style).
- **Inconclusive:** neither.
Margins (exploratory practical-relevance bounds): precision 5 pp; AUPRC 0.03; Dead IoU 1 pp; mIoU 0.3 pp.
10 pp precision gap = "large" descriptor only. Similar Full/noRD AUPRC is NOT read as "Rare-Dead only moves the operating
point"; at most "no evidence that Rare-Dead changes ranking quality", together with matched-recall precision and curve shape.

## 3. Object level (replaces the 50%/10% rule)
8-connected components of GT Dead and predicted Dead per image; one-to-one Hungarian matching on IoU; match iff IoU ≥ τ.
Primary τ = 0.5; sensitivity τ = 0.3 and 0.1; minimum component area 0 px (primary) and 20 px (sensitivity).
Object precision = matched / predicted components, recall = matched / GT components. At δ = 0 and at the
cross-validated δ (below). Unmatched predicted components counted once each, so fragmentation is penalised, not double-counted.
