# Installer

- `VitaFormer_Setup_1.1.0.exe` — Windows 10/11 (64-bit) installer, CPU build.
- `SHA256SUMS.txt` — checksum of the installer. Verify in PowerShell:
  `Get-FileHash .\VitaFormer_Setup_1.1.0.exe -Algorithm SHA256`

The installer is not code-signed. If Windows shows "Windows protected your PC", click **More info → Run anyway**.
